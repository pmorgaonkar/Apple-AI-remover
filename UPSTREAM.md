# Upstream reference

This project was developed after reviewing the public implementation of:

https://github.com/omlahore/RemoveMacAI

The upstream project was used as a technical reference for the feature catalog,
configuration-profile strategy, MobileAsset download override concept, and UAF
asset reset approach.

This repository is an independent implementation. It should not be represented
as the upstream project, an official fork, or an Apple-supported utility unless
that relationship is explicitly established by the repository owner.
